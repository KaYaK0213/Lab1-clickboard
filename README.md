# Librairie Altium
## Les composants R, L et C sont gérés dans Excel
 .dbLib -- Liens de la base de données
 .xlsx -- fichier Excel pour la gestion de la liste de pièces et des liens PCBlib et SCHlib
 .pcbLib -- Empreintes PCB des composants passifs
 .schLib -- Symboles Schématique des composants passifs
 
## Les autres composants sont gérés dans les fichiers Lib

 IC, diode, transistor, etc
  connecteur, trous de vis, etc 
  modèles pour les outils de montage...
